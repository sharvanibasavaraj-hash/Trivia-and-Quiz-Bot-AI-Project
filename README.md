Trivia & Quiz Bot

An interactive quiz application that allows users to test their knowledge across different topics through AI-powered questions.

About

This project was developed to create an interactive quiz experience where users can answer questions, receive instant feedback, track their scores, and get hints when needed.

Features

Multiple quiz categories
AI-generated quiz questions
Instant feedback on answers
Score tracking
Hint and help options
Reset quiz functionality
Automatic progression to the next question
Fallback questions when AI generation is unavailable
Technologies Used

HTML
CSS
JavaScript
Python
Flask
Groq API
How It Works

Users select or explore quiz topics.
Questions are generated using an AI model.
Users submit their answers and receive immediate feedback.
Scores are updated based on their answers.
Users can request hints or help.
The quiz continues with subsequent questions.
Project Structure

Frontend – HTML, CSS and JavaScript
Backend – Python and Flask
API Integration – Groq API
